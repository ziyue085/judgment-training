# 概率校准训练（probability-calibration）

> 概率是这套系统的核心训练目标，也是最容易退化成形容词的部分。

---

## 一、命题化

每个概率必须绑定一个**可判定真假的命题**。

| 坏写法 | 好写法 |
|---|---|
| GDP：60% | P(2015 年该市 GDP ∈ [900, 1100] 亿元) = 60% |
| 增长概率较高 | P(2015 年该市 GDP > 2010 年水平) = 85% |
| 煤炭：85% | P(2015 年该市原煤产量 ∈ [3.5, 4.2] 亿吨) = 65% |

命题四要素：**对象 + 指标 + 期限 + 判定条件**。
缺任一项即为 `PROB_NO_PROPOSITION`，禁止进入锁定。

### 1.1 命题还要落成 `scored_event`（v0.2.3）

光有一句命题文字还不够 —— 规则层需要知道**这个概率到底绑在哪件事上**。
所以每个带 `probability` 的指标必须同时给出 `scored_event`：

| 用户的话 | `proposition` | `scored_event` |
|---|---|---|
| 「2015 年 GDP 落在 900—1100，六成」 | `P(2015 年 GDP ∈ [900,1100] 亿元)` | `{"type":"interval","low":900,"high":1100}` |
| 「2015 年会超过 950，八成」 | `P(2015 年 GDP > 950 亿元)` | `{"type":"threshold","op":">","value":950}` |
| 「三年后比基期高，七成」 | `P(2015 年 GDP > 2010 年水平)` | `{"type":"direction","direction":"up"}` |

缺 `scored_event` → `PROB_SCORED_EVENT_MISSING`（BLOCK）。结构写错 →
`PROB_SCORED_EVENT_INVALID`（BLOCK）。一个指标押两件事 →
`PROB_SCORED_EVENT_MULTIPLE`（BLOCK），需拆成两个指标。

> **最容易犯的错**：直接把 `forecast_low/high` 抄进 `scored_event`。
> 只有当用户真的把概率挂在区间上时才这样写。如果用户明说「我更确定它会超过 420」，
> 那 `scored_event` 就是 `threshold > 420`，**与区间无关** —— 这一点直接决定
> 复盘时 Brier 评的是哪件事。

用户必须同时能说明：
1. 命题是什么（形式化表述）
2. 为什么是这个概率（依据）
3. 最大的不确定性来自哪里
4. **什么情况会让这个命题失败**（失效条件）

第 4 条是强制项。写不出失效条件，说明概率是拍脑袋来的。

## 二、逻辑一致性规则

### 2.1 互斥且穷尽（MECE）集合

若一组命题互斥且穷尽，概率之和应约为 100%（允许 ±5% 的表述误差）。

```text
下降：25%
基本持平：35%
增长：40%
合计 100% ✓
```

若合计为 130% 或 70%，先修结构，再继续。

### 2.2 包含关系

若命题 A 蕴含命题 B（A ⊆ B），则必须 P(A) ≤ P(B)。

```text
P(GDP > 1000) = 70%
P(GDP > 900)  = 60%     ✗ 逻辑错误：超过 1000 必然超过 900
```

正确方向：

```text
P(GDP > 900)  = 70%
P(GDP > 1000) = 60%     ✓
```

### 2.3 区间嵌套

对同一指标，区间的宽度与概率应单调：区间越宽，概率不应更低。

```text
P(GDP ∈ [800, 1000]) = 55%
P(GDP ∈ [900, 950])  = 65%   ✗ 更窄的区间不可能更可能
```

### 2.4 相关指标跨期限一致性

同一对象的短期与长期命题不应互相矛盾。
例如 P(五年内年均增速 > 20%) 与 P(五年累计增幅 < 50%) 不能同时高企。

## 三、统一概率检查（uniform probability）

若 3 个以上指标的预测概率落在极窄区间内（如全部 85% ±2%），触发 `PROB_UNIFORM`。

理由：GDP、人口、利润、产量的不确定性来源完全不同，不可能恰好同值。

教练追问：

> "为什么这些命题恰好都有相同概率？它们的不确定性来源是一样的吗？"

除非用户能给出实质解释（例如"它们都由同一个政策变量决定"），否则要求重新校准。

## 四、点预测与过度精确

### 4.1 默认区间优先

中长期（≥3 年）预测默认形式：

```text
2020 年收入位于 80—100 亿：60%
```

允许给出中心估计，但必须同时保留区间：

```text
核心区间：80—100 亿
中心估计：90 亿
```

中心估计只是**估计中枢**，不是答案。

### 4.2 过度精确判定

触发 `PROB_PRECISION` 的任一条件：
- 预测形式为点估计，且概率 ≥ 80%
- 区间相对宽度过小（区间宽度 / 基期值 < 5%），且概率 ≥ 80%
- 数值精度超出数据本身的精度（如基期数据只有十亿位数量级，却给出 817.3 亿）

处理：
> "5 年后 GDP 恰好 817.3 亿、90% 把握——这个精度超过了数据本身能支撑的程度。给它一个合理区间，并重新校准概率。"

### 4.3 极端概率

出现 ≥ 95% 或 ≤ 5% 的概率时，要求用户说明：**什么样的观测结果会让你承认自己错了？**
若无法给出，视为过度自信。

## 五、校准评分

揭晓后对每个命题计算。**关键前提（v0.2.3）**：Brier 评的必须是
`scored_event` —— 用户**真正押的那件事**，而不是他顺口给出的预测区间。

### 5.1 Brier 分数

把评分命题视为二元事件（命中 = 1，未命中 = 0）：

```text
Brier = (p − o)²
```

其中 p 为用户给出的概率，`o = scored_event_hit`（不是 `interval_hit`）。

- p = 0.6 且命题命中 → Brier = 0.16
- p = 0.6 且命题未命中 → Brier = 0.36

`scored_event_hit` 为 `None`（判定不了）时 **Brier 不出数**，不得按 0 处理。
**结果本身不合法时（`outcome_valid = false`，v0.2.4）Brier 同样不出数** ——
口径不符、期间错位、必填字段缺失的结果，其命中与 Brier 一律 `null`，
`actual_value` 只保留展示。理由：在这三种情形下，`brier = 0` 会被误读成"完美校准"，
比不给分更坏。

**为什么必须绑定到命题**——看这个真实形态：

```text
预测区间 [480, 520]，命题「GDP > 420」，概率 80%，实际 450
```

- 区间没命中：450 ∉ [480, 520] → `interval_hit = false`
- 命题命中了：450 > 420 → `scored_event_hit = true`
- 正确 Brier：`(0.80 − 1)² = 0.04`
- 若错用区间：`(0.80 − 0)² = 0.64` —— 凭空多出 0.6 的"过度自信"

`interval_hit` 与 `scored_event_hit` **分别输出**，可以合法地一真一假：
它们衡量的是两个不同的承诺，不是矛盾。

Brier 越低越好。多命题取平均。

### 5.2 校准偏差（方向性）

| 表现 | 诊断 |
|---|---|
| 高概率命题经常不中 | 过度自信（overconfidence） |
| 低概率命题经常命中 | 过度保守（underconfidence） |
| 区间频繁落空 | 区间过窄 / 忽略了尾部 |
| 概率全部居中（50%—60%） | 逃避表态，未做实质判断 |

一次案例不足以定论，需跨案例累积。校准表见 `prediction-record-template.md`。

### 5.3 常用阈值参考

不要把这些数字当作标准答案，它们只是帮助判断"是否极端"的锚：

| 情形 | 典型频率（仅作参照） |
|---|---|
| 5 年 GDP 翻倍（CAGR ≈ 15%） | 少见，通常需要特殊驱动力 |
| 企业收入 3 年增长 5 倍 | 极罕见 |
| 城市常住人口 3 年增长 40% | 极罕见（除非行政合并/大规模迁移） |
| 利润率长期维持行业极值 | 通常不可持续 |

> 注意：这些是**参照量级**，不是禁止。用户可以预测极端值，但必须给出能支撑它的机制。

## 六、常见概率偏差

1. **锚定效应** — 概率被第一个想到的数字锁定
2. **叙事谬误** — 故事讲得通就给高概率，忽略基准率
3. **可得性偏差** — 用近期记忆中的案例代表整体
4. **区间过窄** — 人类给出的 90% 区间实际命中率通常远低于 90%
5. **确定性幻觉** — 把"我没见过反例"当成"不可能"
6. **逃避表态** — 所有命题都给 50%—60%，不承担判断责任
7. **事后调整** — 揭晓后偷偷修改原概率记录（档案须有时间戳，禁止篡改）
